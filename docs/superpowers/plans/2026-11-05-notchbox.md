# NotchBox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MacBook notch'unu, Mac'te çalan herhangi bir medya kaynağını kontrol eden ve hover'da büyüyen bir müzik paneline çeviren NotchBox uygulamasını, GitHub'a yüklenmeye hazır şekilde yazmak.

**Architecture:** İki SwiftPM hedefi var. `NotchBoxCore` AppKit'e bağımlı olmayan, test edilen saf mantığı içerir: geometri, durum makinesi, oynatma saati, adaptör protokolü ve yeniden deneme politikası. `NotchBox` ise menü çubuğu uygulamasıdır: notch'un üstünde duran bir `NSPanel`, SwiftUI görünümleri, `@Observable` bir `NotchViewModel` ve servisler (mediaremote-adapter süreci, CoreAudio ses, medya tuşları). Şarkı bilgisi, Apple imzalı `/usr/bin/perl` üzerinden çalışan vendored mediaremote-adapter'dan JSON satırları olarak gelir.

**Tech Stack:** Swift 6.4 araç zinciri (Swift 5 dil modu), SwiftUI + AppKit, Observation, CoreAudio, ServiceManagement, Swift Testing, Objective-C adaptör (clang ile derlenir), bash + make. Xcode gerekmez; Command Line Tools yeterli.

**Spec:** `docs/superpowers/specs/2026-11-05-notchbox-design.md`

## Global Constraints

- Minimum macOS 14 (`platforms: [.macOS(.v14)]`, `LSMinimumSystemVersion = 14.0`). Yalnızca arm64 (notch'lu tüm Mac'ler Apple silicon).
- `// swift-tools-version:6.0`, `swiftLanguageModes: [.v5]`.
- Yalnızca Command Line Tools ile derlenmeli. **`@State`, `#Preview` ve diğer SwiftUI makroları kullanılmaz.** macOS 27 SDK'da bunlar makro ve `SwiftUIMacros` eklentisi yalnızca Xcode ile geliyor. Görünüm durumu `NotchViewModel` içinde tutulur. `@Observable` serbesttir (eklentisi CLT'de var).
- Testler yalnızca Swift Testing (`import Testing`) ile yazılır, XCTest kullanılmaz. Testler her zaman `make test` ile çalıştırılır; Makefile, CLT'nin `TestingMacros` eklenti yolunu ekler. Tek bir suite için: `make test FILTER=<SuiteAdı>`.
- Bundle ID ve log alt sistemi: `com.notchbox.NotchBox`.
- Ağ bağlantısı yok. Üçüncü parti Swift paketi yok. Tek dış kod: `Vendor/mediaremote-adapter` git submodule'ü, `v0.7.7` etiketine sabit.
- Diller: `en` (varsayılan) ve `tr`. Kullanıcıya görünen bütün metinler `L10n` üzerinden gelir. Değerler `Resources/<dil>.lproj/Localizable.strings` dosyalarındadır; `bundle.sh` bu dosyaları `Contents/Resources` içine kopyalar.
- Zamanlamalar:
  - Hover: açılma 0.1 sn, kapanma 0.3 sn.
  - Duraklatma zaman aşımı: 300 sn.
  - Yay animasyonu: `response: 0.35`, `dampingFraction: 0.8`. İçerik 0.08 sn gecikmeyle belirir.
  - Adaptör yeniden başlatma: 1, 2, 5, 10, 30 sn. 5 sn'den kısa süren 3 çıkış art arda olursa kısıtlı moda geçilir; kısıtlı modda 60 sn'de bir yeniden denenir.
  - "Hiçbir şey çalmıyor" bekleme süresi: 1.5 sn. Şarkı geçişinde adaptör arada boş payload basıyor (`docs/spike-results.md`).
- Boyutlar:
  - Mini hal: her yana notch yüksekliği + 12pt. Mini kapak: notch yüksekliği − 8pt, köşe yarıçapı 6pt.
  - Açık hal: 400×200pt. Açık-boş hal: 300×80pt.
  - Açık haldeki kapak: 64pt, köşe yarıçapı 10pt.
  - Alt köşe yarıçapı: kapalıyken 8pt, açıkken 20pt.
- Panel hiçbir zaman key window olmaz ve `nonactivatingPanel`'dır.
- AppKit, GCD veya CoreAudio'dan main thread'de gelen callback'ler `MainActor.assumeIsolated { }` ile sarılır.

## Adaptör hakkında bilinenler (ungive/mediaremote-adapter v0.7.7)

- **Çağrı:** `/usr/bin/perl <mediaremote-adapter.pl> <MediaRemoteAdapter.framework dizini> <komut> [seçenekler]`. Yollar mutlak olmalı. Script, `<X>.framework/<X>` ikilisini `DynaLoader` ile yükler ve `adapter_<komut>_env` sembollerini çağırır.
- **Stream:** `stream --no-diff --micros --debounce=100` her değişiklikte bir satır basar: `{"type":"data","diff":false,"payload":{...}}`. Hiçbir şey çalmıyorsa `payload` `{}` olur.
- **Payload alanları:** `bundleIdentifier`, `parentApplicationBundleIdentifier`, `playing`, `title`, `artist`, `album`, `durationMicros`, `elapsedTimeMicros`, `timestampEpochMicros`, `playbackRate`, `artworkData` (base64), `artworkMimeType`.
- **Komutlar:**
  - `send 2`: oynat/duraklat
  - `send 4`: sonraki
  - `send 5`: önceki
  - `seek <mikrosaniye>`: belirli bir konuma sar
- **Sınır:** Komutlar macOS'un aktif saydığı çalara gider.
- **Task 0'da görülen:** Şarkı geçişinde iki dolu satırın arasına boş bir `payload` satırı giriyor. Safari'de kaynak `com.apple.WebKit.GPU`, üst uygulama `com.apple.Safari` olarak geliyor. Ayrıntılar `docs/spike-results.md`'de.
- **Derleme:** Kaynaklar `src/adapter/*.m src/private/*.m src/utility/*.m`. Bayraklar `-fobjc-arc -fvisibility=default`. Bağlanan framework'ler Foundation, AppKit ve UniformTypeIdentifiers.
- **Lisans:** BSD 3-Clause, "Copyright (c) 2025, Jonas van den Berg and contributors".

`scripts/build-adapter.sh`:

```bash
#!/usr/bin/env bash
# Builds MediaRemoteAdapter.framework from the vendored submodule with plain clang (no CMake).
# Output: build/adapter/MediaRemoteAdapter.framework (versioned layout, ad-hoc signed).
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
SRC="$ROOT/Vendor/mediaremote-adapter"
OUT="$ROOT/build/adapter"
FW="$OUT/MediaRemoteAdapter.framework"

if [ ! -f "$SRC/bin/mediaremote-adapter.pl" ]; then
  echo "error: adapter sources missing. Run: git submodule update --init" >&2
  exit 1
fi

rm -rf "$FW"
mkdir -p "$FW/Versions/A/Resources"

cd "$SRC"
shopt -s nullglob
# Same source set as ADAPTER_SOURCES in the upstream CMakeLists.txt.
SOURCES=(src/adapter/*.m src/private/*.m src/utility/*.m)
if [ ${#SOURCES[@]} -eq 0 ]; then
  echo "error: no adapter sources found in $SRC/src" >&2
  exit 1
fi

clang -dynamiclib \
  -fobjc-arc -fmodules -fvisibility=default \
  -arch arm64 -mmacosx-version-min=14.0 \
  -Iinclude -Isrc \
  -framework Foundation -framework AppKit -framework UniformTypeIdentifiers \
  -install_name "@rpath/MediaRemoteAdapter.framework/Versions/A/MediaRemoteAdapter" \
  -o "$FW/Versions/A/MediaRemoteAdapter" \
  "${SOURCES[@]}"

cat > "$FW/Versions/A/Resources/Info.plist" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>CFBundleExecutable</key><string>MediaRemoteAdapter</string>
  <key>CFBundleIdentifier</key><string>com.vandenbe.MediaRemoteAdapter</string>
  <key>CFBundleInfoDictionaryVersion</key><string>6.0</string>
  <key>CFBundleName</key><string>MediaRemoteAdapter</string>
  <key>CFBundlePackageType</key><string>FMWK</string>
  <key>CFBundleShortVersionString</key><string>0.1</string>
  <key>CFBundleVersion</key><string>0.1.0</string>
</dict>
</plist>
PLIST

ln -s A "$FW/Versions/Current"
ln -s Versions/Current/MediaRemoteAdapter "$FW/MediaRemoteAdapter"
ln -s Versions/Current/Resources "$FW/Resources"

codesign --force --sign - "$FW"
echo "Built $FW"
```

```swift
struct NotchGeometryTests {
```

```swift
/// Where the hardware notch is on a screen, in global AppKit coordinates (origin bottom-left).
public struct NotchGeometry: Equatable, Sendable {
    public let screenFrame: CGRect
    public let notchRect: CGRect

    /// Returns nil when the screen has no notch.
    /// Only the widths of the auxiliary areas are used, so their coordinate space does not matter.
    public init?(screenFrame: CGRect, safeAreaTop: CGFloat, auxiliaryTopLeft: CGRect?, auxiliaryTopRight: CGRect?) {
        guard safeAreaTop > 0, let left = auxiliaryTopLeft, let right = auxiliaryTopRight else { return nil }
        let width = screenFrame.width - left.width - right.width
        guard width > 0 else { return nil }
        self.screenFrame = screenFrame
        self.notchRect = CGRect(
            x: screenFrame.minX + left.width,
            y: screenFrame.maxY - safeAreaTop,
            width: width,
            height: safeAreaTop
        )
    }

    public var notchSize: CGSize { notchRect.size }

    /// A frame of `size`, horizontally centered on the notch and pinned to the top of the screen.
    public func panelFrame(for size: CGSize) -> CGRect {
        CGRect(
            x: notchRect.midX - size.width / 2,
            y: screenFrame.maxY - size.height,
            width: size.width,
            height: size.height
        )
    }

    /// Like `CGRect.contains`, but includes the max edges (the cursor can sit on the very top row).
    public static func contains(_ rect: CGRect, _ point: CGPoint) -> Bool {
        guard !rect.isNull, !rect.isEmpty else { return false }
        return point.x >= rect.minX && point.x <= rect.maxX && point.y >= rect.minY && point.y <= rect.maxY
    }
```

```swift
/// Sizes and radii for each display state. All values in points.
public enum NotchLayout {
    public static let miniSidePadding: CGFloat = 12
    public static let expandedSize = CGSize(width: 400, height: 200)
    public static let emptySize = CGSize(width: 300, height: 80)
    public static let expandedArtworkSide: CGFloat = 64
    public static let expandedArtworkRadius: CGFloat = 10
    public static let miniArtworkRadius: CGFloat = 6

    /// Width added on each side of the notch in the mini state.
    public static func miniSideWidth(notch: CGSize) -> CGFloat {
        notch.height + miniSidePadding
    }

    public static func miniArtworkSide(notch: CGSize) -> CGFloat {
        max(0, notch.height - 8)
    }

    public static func size(for state: NotchDisplayState, notch: CGSize) -> CGSize {
        switch state {
        case .idle:
            return notch
        case .mini:
            return CGSize(width: notch.width + 2 * miniSideWidth(notch: notch), height: notch.height)
        case .expanded:
            return CGSize(
                width: max(expandedSize.width, notch.width + 80),
                height: max(expandedSize.height, notch.height + 140)
            )
        case .expandedEmpty:
            return CGSize(
                width: max(emptySize.width, notch.width + 80),
                height: max(emptySize.height, notch.height + 40)
            )
        }
    }

    /// The smallest size that fits every state; the panel window uses this.
    public static func maxSize(notch: CGSize) -> CGSize {
        let states: [NotchDisplayState] = [.idle, .mini, .expanded, .expandedEmpty]
        let sizes = states.map { size(for: $0, notch: notch) }
        return CGSize(
            width: sizes.map(\.width).max() ?? notch.width,
            height: sizes.map(\.height).max() ?? notch.height
        )
    }

    public static func bottomCornerRadius(for state: NotchDisplayState) -> CGFloat {
        state.isOpen ? 20 : 8
    }
}
```

```swift
import Foundation

/// Decides which `NotchDisplayState` to show from hover, media and time.
/// Pure value type: the caller passes the current time and calls `tick(at:)` at `nextDeadline`.
public struct NotchStateMachine: Sendable {
    public struct Timing: Equatable, Sendable {
        public var openDelay: TimeInterval
        public var closeDelay: TimeInterval
        public var pauseTimeout: TimeInterval

        public init(openDelay: TimeInterval = 0.1, closeDelay: TimeInterval = 0.3, pauseTimeout: TimeInterval = 300) {
            self.openDelay = openDelay
            self.closeDelay = closeDelay
            self.pauseTimeout = pauseTimeout
        }
    }

    public enum Media: Equatable, Sendable {
        case nothing
        case playing
        case paused
        /// Degraded mode: no track info, but controls still work.
        case unavailable
    }

    public let timing: Timing
    public private(set) var displayState: NotchDisplayState = .idle

    private var media: Media = .nothing
    private var pausedSince: Date?
    private var isHovering = false
    private var hoverChangedAt = Date.distantPast
    private var isOpen = false

    /// Absorbs floating point error when comparing elapsed time with delays.
    private static let tolerance: TimeInterval = 0.001

    public init(timing: Timing = Timing()) {
        self.timing = timing
    }

    public mutating func setHovering(_ hovering: Bool, at now: Date) {
        if hovering != isHovering {
            isHovering = hovering
            hoverChangedAt = now
        }
        update(at: now)
    }

    public mutating func setMedia(_ newMedia: Media, at now: Date) {
        if newMedia == .paused {
            if media != .paused { pausedSince = now }
        } else {
            pausedSince = nil
        }
        media = newMedia
        update(at: now)
    }

    public mutating func tick(at now: Date) {
        update(at: now)
    }

    /// The next moment the state may change on its own. nil when nothing is pending.
    public var nextDeadline: Date? {
        var candidates: [Date] = []
        if isHovering && !isOpen {
            candidates.append(hoverChangedAt.addingTimeInterval(timing.openDelay))
        }
        if !isHovering && isOpen {
            candidates.append(hoverChangedAt.addingTimeInterval(timing.closeDelay))
        }
        if displayState == .mini, media == .paused, let pausedSince {
            candidates.append(pausedSince.addingTimeInterval(timing.pauseTimeout))
        }
        return candidates.min()
    }

    private mutating func update(at now: Date) {
        let sinceHoverChange = now.timeIntervalSince(hoverChangedAt)
        if isHovering && !isOpen && sinceHoverChange >= timing.openDelay - Self.tolerance {
            isOpen = true
        }
        if !isHovering && isOpen && sinceHoverChange >= timing.closeDelay - Self.tolerance {
            isOpen = false
        }
        if isOpen {
            displayState = media == .nothing ? .expandedEmpty : .expanded
        } else {
            displayState = showsMini(at: now) ? .mini : .idle
        }
    }

    private func showsMini(at now: Date) -> Bool {
        switch media {
        case .playing:
            return true
        case .paused:
            guard let pausedSince else { return false }
            return now.timeIntervalSince(pausedSince) < timing.pauseTimeout - Self.tolerance
        case .nothing, .unavailable:
            return false
        }
    }
}
```

```swift
import Foundation

/// Playback position at a point in time, extrapolated locally so the UI does not poll.
public struct PlaybackClock: Equatable, Sendable {
    /// Seconds elapsed at `timestamp`.
    public var elapsed: TimeInterval
    public var timestamp: Date
    public var rate: Double
    public var isPlaying: Bool
    /// Track length in seconds; nil or 0 for live streams.
    public var duration: TimeInterval?

    public init(elapsed: TimeInterval, timestamp: Date, rate: Double, isPlaying: Bool, duration: TimeInterval?) {
        self.elapsed = elapsed
        self.timestamp = timestamp
        self.rate = rate
        self.isPlaying = isPlaying
        self.duration = duration
    }

    public var hasDuration: Bool { (duration ?? 0) > 0 }

    public func elapsed(at now: Date) -> TimeInterval {
        var value = elapsed
        if isPlaying {
            let effectiveRate = rate > 0 ? rate : 1
            value += max(0, now.timeIntervalSince(timestamp)) * effectiveRate
        }
        if let duration, duration > 0 {
            value = min(value, duration)
        }
        return max(0, value)
    }

    public func seeked(to position: TimeInterval, at now: Date) -> PlaybackClock {
        var copy = self
        copy.elapsed = position
        copy.timestamp = now
        return copy
    }
}
```

```swift
import Foundation

public enum TimeFormatter {
    /// "1:12", "1:02:03". Negative values become "0:00".
    public static func string(from seconds: TimeInterval) -> String {
        let total = Int(max(0, seconds).rounded(.down))
        let hours = total / 3600
        let minutes = (total % 3600) / 60
        let secs = total % 60
        if hours > 0 {
            return String(format: "%d:%02d:%02d", hours, minutes, secs)
        }
        return String(format: "%d:%02d", minutes, secs)
    }

    /// "-2:31"
    public static func remaining(elapsed: TimeInterval, duration: TimeInterval) -> String {
        "-" + string(from: max(0, duration - elapsed))
    }
}
```

```swift
import Foundation

/// Payload of a mediaremote-adapter line produced with `--micros`.
/// Every field is decoded leniently: a field with an unexpected type becomes nil
/// instead of dropping the whole line.
struct NowPlayingPayload: Decodable, Equatable {
    var bundleIdentifier: String?
    var parentApplicationBundleIdentifier: String?
    var playing: Bool?
    var title: String?
    var artist: String?
    var album: String?
    var durationMicros: Double?
    var elapsedTimeMicros: Double?
    var timestampEpochMicros: Double?
    var playbackRate: Double?
    var artworkData: String?

    enum CodingKeys: String, CodingKey {
        case bundleIdentifier, parentApplicationBundleIdentifier, playing, title, artist, album
        case durationMicros, elapsedTimeMicros, timestampEpochMicros, playbackRate, artworkData
    }

    init(from decoder: Decoder) throws {
        let container = try decoder.container(keyedBy: CodingKeys.self)
        bundleIdentifier = try? container.decodeIfPresent(String.self, forKey: .bundleIdentifier)
        parentApplicationBundleIdentifier = try? container.decodeIfPresent(String.self, forKey: .parentApplicationBundleIdentifier)
        title = try? container.decodeIfPresent(String.self, forKey: .title)
        artist = try? container.decodeIfPresent(String.self, forKey: .artist)
        album = try? container.decodeIfPresent(String.self, forKey: .album)
        durationMicros = try? container.decodeIfPresent(Double.self, forKey: .durationMicros)
        elapsedTimeMicros = try? container.decodeIfPresent(Double.self, forKey: .elapsedTimeMicros)
        timestampEpochMicros = try? container.decodeIfPresent(Double.self, forKey: .timestampEpochMicros)
        playbackRate = try? container.decodeIfPresent(Double.self, forKey: .playbackRate)
        artworkData = try? container.decodeIfPresent(String.self, forKey: .artworkData)
        if let flag = try? container.decodeIfPresent(Bool.self, forKey: .playing) {
            playing = flag
        } else if let number = try? container.decodeIfPresent(Int.self, forKey: .playing) {
            playing = number != 0
        } else {
            playing = nil
        }
    }
}

/// One `stream` line: {"type":"data","diff":false,"payload":{...}}
struct StreamEnvelope: Decodable {
    let type: String
    let payload: NowPlayingPayload?
}

public enum AdapterStreamParser {
    public enum Result: Equatable, Sendable {
        case nothingPlaying
        case info(NowPlayingInfo)
        case invalid
    }

    public static func parse(line: String, receivedAt now: Date) -> Result {
        let trimmed = line.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty,
              let data = trimmed.data(using: .utf8),
              let envelope = try? JSONDecoder().decode(StreamEnvelope.self, from: data),
              envelope.type == "data"
        else { return .invalid }
        guard let payload = envelope.payload, let info = makeInfo(from: payload, receivedAt: now) else {
            return .nothingPlaying
        }
        return .info(info)
    }

    static func makeInfo(from payload: NowPlayingPayload, receivedAt now: Date) -> NowPlayingInfo? {
        guard let title = payload.title, !title.isEmpty, let bundle = payload.bundleIdentifier else { return nil }
        let timestamp = payload.timestampEpochMicros.map { Date(timeIntervalSince1970: $0 / 1_000_000) } ?? now
        let clock = PlaybackClock(
            elapsed: (payload.elapsedTimeMicros ?? 0) / 1_000_000,
            timestamp: timestamp,
            rate: payload.playbackRate ?? 1,
            isPlaying: payload.playing ?? false,
            duration: payload.durationMicros.map { $0 / 1_000_000 }
        )
        return NowPlayingInfo(
            title: title,
            artist: nonEmpty(payload.artist),
            album: nonEmpty(payload.album),
            sourceBundleIdentifier: nonEmpty(payload.parentApplicationBundleIdentifier) ?? bundle,
            clock: clock,
            artwork: payload.artworkData.flatMap { Data(base64Encoded: $0, options: .ignoreUnknownCharacters) }
        )
    }

    private static func nonEmpty(_ value: String?) -> String? {
        guard let value, !value.isEmpty else { return nil }
        return value
    }
}
```

```swift
import Foundation

/// Restart policy for the adapter `stream` process.
public struct AdapterSupervisor: Sendable {
    public static let restartDelays: [TimeInterval] = [1, 2, 5, 10, 30]
    public static let quickExitWindow: TimeInterval = 5
    public static let quickExitLimit = 3
    public static let degradedRetryInterval: TimeInterval = 60

    public private(set) var isDegraded = false

    private var startedAt: Date?
    private var restartIndex = 0
    private var consecutiveQuickExits = 0

    public init() {}

    public mutating func processStarted(at now: Date) {
        startedAt = now
    }

    /// Any parseable line proves the adapter works.
    public mutating func receivedOutput() {
        restartIndex = 0
        consecutiveQuickExits = 0
        isDegraded = false
    }

    /// Call when the process exits or fails to launch. Returns the delay before the next launch.
    public mutating func processExited(at now: Date) -> TimeInterval {
        let ranFor = startedAt.map { now.timeIntervalSince($0) } ?? 0
        startedAt = nil
        if ranFor < Self.quickExitWindow {
            consecutiveQuickExits += 1
        } else {
            consecutiveQuickExits = 0
        }
        if consecutiveQuickExits >= Self.quickExitLimit {
            isDegraded = true
        }
        if isDegraded {
            return Self.degradedRetryInterval
        }
        let delay = Self.restartDelays[min(restartIndex, Self.restartDelays.count - 1)]
        restartIndex += 1
        return delay
    }
}
```

```swift
/// Finds the built-in notched screen and reports changes (monitors, resolution, lid).
@MainActor
final class ScreenWatcher {
    var onChange: ((NotchGeometry?) -> Void)?
    private var observer: NSObjectProtocol?

    func start() {
        observer = NotificationCenter.default.addObserver(
            forName: NSApplication.didChangeScreenParametersNotification, object: nil, queue: .main
        ) { [weak self] _ in
            MainActor.assumeIsolated { self?.refresh() }
        }
        refresh()
    }

    func refresh() {
        onChange?(Self.currentGeometry())
    }

    static func currentGeometry() -> NotchGeometry? {
        for screen in NSScreen.screens {
            if let geometry = NotchGeometry(
                screenFrame: screen.frame,
                safeAreaTop: screen.safeAreaInsets.top,
                auxiliaryTopLeft: screen.auxiliaryTopLeftArea,
                auxiliaryTopRight: screen.auxiliaryTopRightArea
            ) {
                return geometry
            }
        }
        return nil
    }
}
```

```swift
import AppKit
import NotchBoxCore

/// Reports whether the cursor is inside `hotZone` (global screen coordinates).
/// Mouse-moved monitors need no permission.
@MainActor
final class HoverTracker {
    var hotZone: CGRect = .null {
        didSet { evaluate() }
    }
    var onHoverChange: ((Bool) -> Void)?
    private(set) var isHovering = false
    private var monitors: [Any] = []

    func start() {
        guard monitors.isEmpty else { return }
        let mask: NSEvent.EventTypeMask = [.mouseMoved, .leftMouseDragged, .leftMouseUp]
        if let global = NSEvent.addGlobalMonitorForEvents(matching: mask, handler: { [weak self] _ in
            MainActor.assumeIsolated { self?.evaluate() }
        }) {
            monitors.append(global)
        }
        if let local = NSEvent.addLocalMonitorForEvents(matching: mask, handler: { [weak self] event in
            MainActor.assumeIsolated { self?.evaluate() }
            return event
        }) {
            monitors.append(local)
        }
        evaluate()
    }

    func stop() {
        monitors.forEach(NSEvent.removeMonitor)
        monitors.removeAll()
    }

    private func evaluate() {
        let inside = NotchGeometry.contains(hotZone, NSEvent.mouseLocation)
        // Keep the panel open while a drag that started inside it (a slider) continues outside.
        let dragging = isHovering && (NSEvent.pressedMouseButtons & 1) != 0
        let hovering = inside || dragging
        guard hovering != isHovering else { return }
        isHovering = hovering
        onHoverChange?(hovering)
    }
}
```

```swift
import AppKit
import NotchBoxCore
import Observation

/// Single source of truth for the views. Combines the state machine with the services.
@MainActor
@Observable
final class NotchViewModel {
    private(set) var displayState: NotchDisplayState = .idle
    private(set) var notchSize = CGSize(width: 185, height: 32)
    private(set) var nowPlaying: NowPlayingState = .nothing
    private(set) var artworkImage: NSImage?
    private(set) var artworkVersion = 0
    private(set) var sourceAppIcon: NSImage?
    private(set) var volume: Float = 0
    private(set) var isVolumeSettable = false
    /// Slider position while the user drags the progress bar.
    private(set) var scrubPosition: TimeInterval?

    @ObservationIgnored var onDisplayStateChange: ((NotchDisplayState) -> Void)?
    @ObservationIgnored private var machine = NotchStateMachine()
    @ObservationIgnored private var deadlineTimer: Timer?
    @ObservationIgnored private let nowPlayingService: NowPlayingService?
    @ObservationIgnored private let volumeControl: VolumeControlling?
    @ObservationIgnored private let mediaKeys: MediaKeySending?
    @ObservationIgnored private let now: () -> Date

    init(
        nowPlayingService: NowPlayingService? = nil,
        volumeControl: VolumeControlling? = nil,
        mediaKeys: MediaKeySending? = nil,
        now: @escaping () -> Date = Date.init
    ) {
        self.nowPlayingService = nowPlayingService
        self.volumeControl = volumeControl
        self.mediaKeys = mediaKeys
        self.now = now
    }

    var info: NowPlayingInfo? {
        if case .info(let info) = nowPlaying { return info }
        return nil
    }

    var isUnavailable: Bool { nowPlaying == .unavailable }

    var contentSize: CGSize { NotchLayout.size(for: displayState, notch: notchSize) }

    func start() {
        nowPlayingService?.onChange = { [weak self] state in self?.nowPlayingChanged(state) }
        volumeControl?.onChange = { [weak self] in self?.volumeChanged() }
        nowPlayingService?.start()
        volumeControl?.start()
        volumeChanged()
    }

    func stop() {
        deadlineTimer?.invalidate()
        nowPlayingService?.stop()
    }

    func setNotchSize(_ size: CGSize) {
        guard size != notchSize else { return }
        notchSize = size
        onDisplayStateChange?(displayState)
    }

    func hoverChanged(_ hovering: Bool) {
        machine.setHovering(hovering, at: now())
        apply()
    }

    func togglePlayPause() { perform(.togglePlayPause) }
    func next() { perform(.next) }
    func previous() { perform(.previous) }

    func seek(to position: TimeInterval) {
        perform(.seek(to: position))
        // Move the bar right away instead of waiting for the next adapter line.
        if case .info(var info) = nowPlaying {
            info.clock = info.clock.seeked(to: position, at: now())
            nowPlaying = .info(info)
        }
    }

    func scrub(to position: TimeInterval) {
        scrubPosition = position
    }

    func endScrub() {
        guard let position = scrubPosition else { return }
        scrubPosition = nil
        seek(to: position)
    }

    func setVolume(_ value: Float) {
        volumeControl?.setVolume(value)
    }

    func openSourceApp() {
        guard let bundleIdentifier = info?.sourceBundleIdentifier else { return }
        AppIconProvider.open(bundleIdentifier: bundleIdentifier)
    }

    private func perform(_ command: MediaCommand) {
        if isUnavailable {
            if let code = MediaKeyCode.code(for: command) { mediaKeys?.send(code: code) }
        } else {
            nowPlayingService?.send(command)
        }
    }

    private func nowPlayingChanged(_ state: NowPlayingState) {
        let old = info
        nowPlaying = state
        let current = info
        if current?.artwork != old?.artwork {
            artworkImage = current?.artwork.flatMap { NSImage(data: $0) }
            artworkVersion += 1
        }
        if current?.sourceBundleIdentifier != old?.sourceBundleIdentifier {
            sourceAppIcon = current.flatMap { AppIconProvider.icon(for: $0.sourceBundleIdentifier) }
        }
        machine.setMedia(state.machineMedia, at: now())
        apply()
    }

    private func volumeChanged() {
        volume = volumeControl?.volume ?? 0
        isVolumeSettable = volumeControl?.isSettable ?? false
    }

    private func tick() {
        machine.tick(at: now())
        apply()
    }

    private func apply() {
        let newState = machine.displayState
        if newState != displayState {
            displayState = newState
            onDisplayStateChange?(newState)
        }
        scheduleNextTick()
    }

    private func scheduleNextTick() {
        deadlineTimer?.invalidate()
        deadlineTimer = nil
        guard let deadline = machine.nextDeadline else { return }
        let interval = max(0.01, deadline.timeIntervalSince(now()) + 0.005)
        deadlineTimer = Timer.scheduledTimer(withTimeInterval: interval, repeats: false) { [weak self] _ in
            MainActor.assumeIsolated { self?.tick() }
        }
    }
}
```

```swift
import NotchBoxCore
import SwiftUI

struct NotchRootView: View {
    let model: NotchViewModel

    var body: some View {
        let size = model.contentSize
        ZStack(alignment: .top) {
            NotchShape(bottomRadius: NotchLayout.bottomCornerRadius(for: model.displayState))
                .fill(Color.black)
                .frame(width: size.width, height: size.height)
            content
                .frame(width: size.width, height: size.height, alignment: .top)
                .clipped()
        }
        .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .top)
        .animation(.spring(response: 0.35, dampingFraction: 0.8), value: model.displayState)
    }

    @ViewBuilder
    private var content: some View {
        switch model.displayState {
        case .idle, .mini, .expanded:
            // .mini and .expanded need a now playing service; their views arrive in Task 9.
            Color.clear
        case .expandedEmpty:
            NothingPlayingView()
                .padding(.top, model.notchSize.height)
                .transition(.notchContent)
        }
    }
}

    /// Content appears just after the shape starts growing and leaves before it shrinks.
    static var notchContent: AnyTransition {
        .asymmetric(
            insertion: .opacity.animation(.easeOut(duration: 0.15).delay(0.08)),
            removal: .opacity.animation(.easeIn(duration: 0.08))
        )
    }
}
```

```swift
import AppKit
import NotchBoxCore
import SwiftUI

/// Owns the panel: positions it over the notch and keeps hover/click handling in sync with the state.
@MainActor
final class NotchWindowController {
    private let panel = NotchPanel()
    private let model: NotchViewModel
    private let hoverTracker = HoverTracker()
    private let screenWatcher = ScreenWatcher()
    private var geometry: NotchGeometry?

    init(model: NotchViewModel) {
        self.model = model
        let hostingView = FirstMouseHostingView(rootView: NotchRootView(model: model))
        hostingView.sizingOptions = []
        panel.contentView = hostingView
    }

    func start() {
        model.onDisplayStateChange = { [weak self] _ in self?.updateInteraction() }
        hoverTracker.onHoverChange = { [weak self] hovering in self?.model.hoverChanged(hovering) }
        screenWatcher.onChange = { [weak self] geometry in self?.apply(geometry) }
        screenWatcher.start()
        hoverTracker.start()
    }

    private func apply(_ geometry: NotchGeometry?) {
        self.geometry = geometry
        guard let geometry else {
            panel.orderOut(nil)
            hoverTracker.hotZone = .null
            return
        }
        model.setNotchSize(geometry.notchSize)
        panel.setFrame(geometry.panelFrame(for: NotchLayout.maxSize(notch: geometry.notchSize)), display: true)
        panel.orderFrontRegardless()
        updateInteraction()
    }

    private func updateInteraction() {
        guard let geometry else { return }
        panel.ignoresMouseEvents = !model.displayState.isOpen
        hoverTracker.hotZone = geometry.panelFrame(for: model.contentSize)
    }
}
```

```swift
import Foundation
import NotchBoxCore

/// Absolute paths of the bundled adapter script and framework.
struct AdapterLocation {
    /// `defaults write com.notchbox.NotchBox AdapterScriptOverride /path` replaces the script
    /// (a missing path is how degraded mode is tested by hand).
    static let scriptOverrideKey = "AdapterScriptOverride"

    let scriptPath: String
    let frameworkPath: String

    var baseArguments: [String] {
        AdapterCommandLine.baseArguments(scriptPath: scriptPath, frameworkPath: frameworkPath)
    }

    static func resolve(bundle: Bundle = .main, defaults: UserDefaults = .standard) -> AdapterLocation {
        let script = defaults.string(forKey: scriptOverrideKey)
            ?? bundle.path(forResource: "mediaremote-adapter", ofType: "pl")
            ?? "/nonexistent/mediaremote-adapter.pl"
        let framework = bundle.privateFrameworksPath.map { $0 + "/MediaRemoteAdapter.framework" }
            ?? "/nonexistent/MediaRemoteAdapter.framework"
        return AdapterLocation(scriptPath: script, frameworkPath: framework)
    }
}
```

```swift
/// Runs `mediaremote-adapter.pl … stream` for the app's lifetime and restarts it when it exits.
@MainActor
final class AdapterNowPlayingService: NowPlayingService {
    /// On a track change the adapter briefly reports an empty payload between two tracks.
    /// "Nothing playing" is applied only if no track arrives within this time (see docs/spike-results.md).
    static let nothingPlayingGrace: TimeInterval = 1.5

    private(set) var state: NowPlayingState = .nothing
    var onChange: ((NowPlayingState) -> Void)?

    private let location: AdapterLocation
    private let logger = Logger(subsystem: AppConstants.logSubsystem, category: "adapter")
    private var process: Process?
    private var supervisor = AdapterSupervisor()
    private var restartWork: DispatchWorkItem?
    private var pendingNothing: DispatchWorkItem?
    private var buffer = Data()
    private var isStopped = true

    init(location: AdapterLocation) {
        self.location = location
    }

    func start() {
        guard isStopped else { return }
        isStopped = false
        launch()
    }

    func stop() {
        isStopped = true
        restartWork?.cancel()
        restartWork = nil
        cancelPendingNothing()
        process?.terminate()
        process = nil
    }

    /// Called after wake: launch now if the process is not running (skips any pending delay).
    func ensureRunning() {
        guard !isStopped, process == nil else { return }
        restartWork?.cancel()
        restartWork = nil
        launch()
    }

    func send(_ command: MediaCommand) {
        let commandProcess = Process()
        commandProcess.executableURL = URL(fileURLWithPath: AdapterCommandLine.perlPath)
        commandProcess.arguments = location.baseArguments + AdapterCommandLine.arguments(for: command)
        commandProcess.standardOutput = FileHandle.nullDevice
        commandProcess.standardError = FileHandle.nullDevice
        do {
            try commandProcess.run()
        } catch {
            logger.error("Command failed to launch: \(error.localizedDescription, privacy: .public)")
        }
    }

    private func launch() {
        buffer.removeAll()
        let streamProcess = Process()
        streamProcess.executableURL = URL(fileURLWithPath: AdapterCommandLine.perlPath)
        streamProcess.arguments = location.baseArguments + AdapterCommandLine.streamArguments
        let stdout = Pipe()
        let stderr = Pipe()
        streamProcess.standardOutput = stdout
        streamProcess.standardError = stderr

        stdout.fileHandleForReading.readabilityHandler = { [weak self] handle in
            let data = handle.availableData
            guard !data.isEmpty else { return }
            DispatchQueue.main.async {
                MainActor.assumeIsolated { self?.consume(data, from: streamProcess) }
            }
        }
        let logger = self.logger
        stderr.fileHandleForReading.readabilityHandler = { handle in
            let data = handle.availableData
            guard !data.isEmpty, let text = String(data: data, encoding: .utf8) else { return }
            logger.error("adapter stderr: \(text, privacy: .public)")
        }
        streamProcess.terminationHandler = { [weak self] finished in
            stdout.fileHandleForReading.readabilityHandler = nil
            stderr.fileHandleForReading.readabilityHandler = nil
            DispatchQueue.main.async {
                MainActor.assumeIsolated { self?.handleExit(of: finished) }
            }
        }

        supervisor.processStarted(at: Date())
        do {
            try streamProcess.run()
            process = streamProcess
        } catch {
            logger.error("Adapter failed to launch: \(error.localizedDescription, privacy: .public)")
            scheduleRestart()
        }
    }

    private func consume(_ data: Data, from source: Process) {
        guard source === process else { return }
        buffer.append(data)
        while let newline = buffer.firstIndex(of: 0x0A) {
            let lineData = buffer[buffer.startIndex..<newline]
            buffer.removeSubrange(buffer.startIndex...newline)
            if let line = String(data: lineData, encoding: .utf8) {
                handle(line: line)
            }
        }
    }

    private func handle(line: String) {
        switch AdapterStreamParser.parse(line: line, receivedAt: Date()) {
        case .invalid:
            logger.debug("Skipped unparseable adapter line")
        case .nothingPlaying:
            supervisor.receivedOutput()
            scheduleNothingPlaying()
        case .info(let info):
            supervisor.receivedOutput()
            cancelPendingNothing()
            update(.info(info))
        }
    }

    private func scheduleNothingPlaying() {
        guard state != .nothing, pendingNothing == nil else { return }
        let work = DispatchWorkItem { [weak self] in
            MainActor.assumeIsolated {
                guard let self else { return }
                self.pendingNothing = nil
                self.update(.nothing)
            }
        }
        pendingNothing = work
        DispatchQueue.main.asyncAfter(deadline: .now() + Self.nothingPlayingGrace, execute: work)
    }

    private func cancelPendingNothing() {
        pendingNothing?.cancel()
        pendingNothing = nil
    }

    private func handleExit(of finished: Process) {
        guard finished === process else { return }
        process = nil
        logger.notice("Adapter exited with status \(finished.terminationStatus)")
        guard !isStopped else { return }
        scheduleRestart()
    }

    private func scheduleRestart() {
        let delay = supervisor.processExited(at: Date())
        if supervisor.isDegraded {
            cancelPendingNothing()
            update(.unavailable)
        }
        let work = DispatchWorkItem { [weak self] in
            MainActor.assumeIsolated {
                guard let self, !self.isStopped else { return }
                self.restartWork = nil
                self.launch()
            }
        }
        restartWork = work
        DispatchQueue.main.asyncAfter(deadline: .now() + delay, execute: work)
    }

    private func update(_ newState: NowPlayingState) {
        guard newState != state else { return }
        state = newState
        onChange?(newState)
    }
}
```

```swift
import AudioToolbox
import CoreAudio
import Foundation

/// System output volume of the default output device, via CoreAudio.
@MainActor
final class VolumeService: VolumeControlling {
    private(set) var volume: Float = 0
    private(set) var isSettable = false
    var onChange: (() -> Void)?

    private var deviceID = AudioObjectID(kAudioObjectUnknown)
    private var deviceListener: AudioObjectPropertyListenerBlock?
    private var volumeListener: AudioObjectPropertyListenerBlock?

    func start() {
        guard deviceListener == nil else { return }
        var address = Self.defaultDeviceAddress()
        let listener: AudioObjectPropertyListenerBlock = { [weak self] _, _ in
            MainActor.assumeIsolated { self?.attachToDefaultDevice() }
        }
        if AudioObjectAddPropertyListenerBlock(AudioObjectID(kAudioObjectSystemObject), &address, DispatchQueue.main, listener) == noErr {
            deviceListener = listener
        }
        attachToDefaultDevice()
    }

    func setVolume(_ value: Float) {
        guard isSettable else { return }
        var address = Self.volumeAddress()
        var newValue = Float32(min(max(value, 0), 1))
        let status = AudioObjectSetPropertyData(deviceID, &address, 0, nil, UInt32(MemoryLayout<Float32>.size), &newValue)
        if status == noErr {
            volume = newValue
            onChange?()
        }
    }

    private func attachToDefaultDevice() {
        detachVolumeListener()
        deviceID = Self.currentDefaultDevice()
        if deviceID != kAudioObjectUnknown {
            var address = Self.volumeAddress()
            let listener: AudioObjectPropertyListenerBlock = { [weak self] _, _ in
                MainActor.assumeIsolated { self?.refresh() }
            }
            if AudioObjectAddPropertyListenerBlock(deviceID, &address, DispatchQueue.main, listener) == noErr {
                volumeListener = listener
            }
        }
        refresh()
    }

    private func detachVolumeListener() {
        guard let listener = volumeListener, deviceID != kAudioObjectUnknown else { return }
        var address = Self.volumeAddress()
        _ = AudioObjectRemovePropertyListenerBlock(deviceID, &address, DispatchQueue.main, listener)
        volumeListener = nil
    }

    private func refresh() {
        var address = Self.volumeAddress()
        let hasVolume = deviceID != kAudioObjectUnknown && AudioObjectHasProperty(deviceID, &address)
        var settable: DarwinBoolean = false
        if hasVolume {
            _ = AudioObjectIsPropertySettable(deviceID, &address, &settable)
            var value = Float32(0)
            var size = UInt32(MemoryLayout<Float32>.size)
            if AudioObjectGetPropertyData(deviceID, &address, 0, nil, &size, &value) == noErr {
                volume = value
            }
        }
        isSettable = hasVolume && settable.boolValue
        onChange?()
    }

    private static func currentDefaultDevice() -> AudioObjectID {
        var address = defaultDeviceAddress()
        var id = AudioObjectID(kAudioObjectUnknown)
        var size = UInt32(MemoryLayout<AudioObjectID>.size)
        let status = AudioObjectGetPropertyData(AudioObjectID(kAudioObjectSystemObject), &address, 0, nil, &size, &id)
        return status == noErr ? id : AudioObjectID(kAudioObjectUnknown)
    }

    private static func defaultDeviceAddress() -> AudioObjectPropertyAddress {
        AudioObjectPropertyAddress(
            mSelector: kAudioHardwarePropertyDefaultOutputDevice,
            mScope: kAudioObjectPropertyScopeGlobal,
            mElement: kAudioObjectPropertyElementMain
        )
    }

    private static func volumeAddress() -> AudioObjectPropertyAddress {
        AudioObjectPropertyAddress(
            mSelector: kAudioHardwareServiceDeviceProperty_VirtualMainVolume,
            mScope: kAudioDevicePropertyScopeOutput,
            mElement: kAudioObjectPropertyElementMain
        )
    }
}
```

```swift
import AppKit
import ApplicationServices

/// Degraded-mode fallback: posts system media key events. Needs Accessibility permission,
/// which is requested the first time a key is sent.
@MainActor
final class MediaKeySender: MediaKeySending {
    func send(code: Int32) {
        guard isTrusted(prompt: true) else { return }
        post(code: code, down: true)
        post(code: code, down: false)
    }

    private func isTrusted(prompt: Bool) -> Bool {
        let options = ["AXTrustedCheckOptionPrompt": prompt] as CFDictionary
        return AXIsProcessTrustedWithOptions(options)
    }

    private func post(code: Int32, down: Bool) {
        let flags = NSEvent.ModifierFlags(rawValue: down ? 0xA00 : 0xB00)
        let data1 = Int((code << 16) | ((down ? 0xA : 0xB) << 8))
        let event = NSEvent.otherEvent(
            with: .systemDefined,
            location: .zero,
            modifierFlags: flags,
            timestamp: 0,
            windowNumber: 0,
            context: nil,
            subtype: 8,
            data1: data1,
            data2: -1
        )
        event?.cgEvent?.post(tap: .cghidEventTap)
    }
}
```

```swift
import AppKit

@MainActor
final class AppDelegate: NSObject, NSApplicationDelegate {
    private var statusItemController: StatusItemController?
    private var windowController: NotchWindowController?
    private var model: NotchViewModel?
    private var wakeObserver: NSObjectProtocol?

    func applicationDidFinishLaunching(_ notification: Notification) {
        statusItemController = StatusItemController()

        let nowPlayingService = AdapterNowPlayingService(location: .resolve())
        let model = NotchViewModel(
            nowPlayingService: nowPlayingService,
            volumeControl: VolumeService(),
            mediaKeys: MediaKeySender()
        )
        let windowController = NotchWindowController(model: model)
        windowController.start()
        model.start()
        self.model = model
        self.windowController = windowController

        wakeObserver = NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didWakeNotification, object: nil, queue: .main
        ) { _ in
            MainActor.assumeIsolated { nowPlayingService.ensureRunning() }
        }
    }

    func applicationWillTerminate(_ notification: Notification) {
        model?.stop()
    }
}
```

```bash
#!/usr/bin/env bash
# Zips build/NotchBox.app into dist/NotchBox-<version>.zip for GitHub Releases.
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
APP="$ROOT/build/NotchBox.app"
VERSION="$(/usr/libexec/PlistBuddy -c 'Print CFBundleShortVersionString' "$ROOT/Resources/Info.plist")"
ZIP="$ROOT/dist/NotchBox-$VERSION.zip"

if [ ! -d "$APP" ]; then
  echo "error: $APP not found. Run: make app" >&2
  exit 1
fi

mkdir -p "$ROOT/dist"
rm -f "$ZIP"
ditto -c -k --keepParent "$APP" "$ZIP"
echo "Created $ZIP"
```

`README.md`:

````markdown
# NotchBox

Control whatever is playing on your Mac from the MacBook notch.

![NotchBox](docs/screenshot.png)

- While music plays, a mini cover sits left of the notch and a small waveform moves on its right.
- Hover the notch and it grows into a player: artwork, title, artist, previous / play-pause / next,
  a draggable progress bar, a volume slider and the icon of the app that is playing.
- Works with any app that reports "Now Playing" to macOS: Spotify, Apple Music, YouTube in your browser and more.
- English and Turkish, picked from your system language.

## Requirements

- A MacBook with a notch (Apple silicon)
- macOS 14 or later

## Install

1. Download `NotchBox-<version>.zip` from [Releases](../../releases) and unzip it.
2. Move `NotchBox.app` to `/Applications`.
3. NotchBox is not notarized, so macOS blocks it the first time. Remove the quarantine flag:
   ```bash
   xattr -dr com.apple.quarantine /Applications/NotchBox.app
   ```
4. Open NotchBox. A music note icon appears in the menu bar; use it for "Launch at Login" and "Quit".

## Privacy

NotchBox never connects to the network. Track info stays on your Mac.

## How it works

Since macOS 15.4, apps cannot read "Now Playing" info directly. NotchBox bundles
[mediaremote-adapter](https://github.com/ungive/mediaremote-adapter), which reads it through the
system's Apple-signed `/usr/bin/perl`. This is not an official Apple API, and a future macOS update may break it.
If that happens, NotchBox switches to a limited mode: it can no longer show the track, but the buttons
keep working through media keys (this needs Accessibility permission, asked only then).

## Known limitations

- Commands go to the player macOS considers active; you cannot pick a specific app.
- The volume slider controls the system volume, not per-app volume.
- Only the built-in display is used.

## Development

Needs only the Xcode Command Line Tools (`xcode-select --install`); Xcode itself is optional.

```bash
git clone --recursive <this repo>
make test   # unit tests (Swift Testing)
make run    # build build/NotchBox.app and open it
make dist   # dist/NotchBox-<version>.zip
```

- Do not use `@State` or `#Preview`: with only the Command Line Tools, the SwiftUI macro plugin is missing.
  Keep view state in `NotchViewModel`.
- Accessibility permission is tied to the app's signature. Ad-hoc signed builds get a new signature on
  every build, so you may need to grant it again while developing.
- Before a release, go through [docs/manual-testing.md](docs/manual-testing.md).
````
